# SIM Manager v0.1.0

First Windows x64 portable release of SIM Manager.

Download `SIMManager-0.1.0-win-x64.zip`, extract the whole folder, and open
`SIMManager.exe`. Keep `_internal` beside the executable. Python installation and
administrator access are not required. A SHA-256 checksum is provided separately.
This build is unsigned.

Included:

- Saved SIM profiles, active-SIM recognition, renaming and a compact Home dashboard.
- Official MyDITO sign-in in an isolated browser, verified account values, manual
  refresh and automatic refresh with 15/30/60-second choices and rate-limit handling.
- A tray dashboard sharing Home's data, with Refresh, Open and Exit actions.
- Opt-in Start with Windows. Closing keeps the app in the tray by default on new
  installs; existing saved preferences are respected.
- D2 router login, optional Windows-protected remembered credentials and existing
  read-only connection diagnostics.
- A read-only 20-message inbox with full-message windows and explicit copy actions.
- The supplied application artwork as the logo and native executable icon.

Limits:

- DITO account integration and the existing D2 router integration only. Smart/TNT
  support and History implementation are not included.
- MyDITO sessions remain memory-only; restarting requires sign-in again.
- Account data is source/schema dependent. Missing values remain unavailable,
  temporary failures retain stale verified values, and no totals are invented.
- Data progress is hidden when a verified total allowance is unavailable.
- Moving/removing the portable folder requires updating/disabling Start with
  Windows from Settings. Use Exit to stop the app fully before replacing it.

Verification: **983 source tests passed** (640 backend, 264 GUI, 79 JavaScript).
The frozen EXE passed all **17 offline smoke checks**, including a real blank
browser view, tray lifecycle and cleanup. Package integrity and SHA-256 checks
passed. Detailed results are recorded in the completed Windows release plan.
